# Products Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the product catalog page with create, update, soft delete, classification, product/service type, and current-stock visibility.

**Architecture:** One Livewire 4 single-file index page under `livewire.catalog.products`, following the existing categories/brands pattern, plus three child SFCs for create, update, and delete. Stock is computed per page with two `withSum` subqueries over `stock_movements`; the schema gains a `type` column by editing the existing products migration.

**Tech Stack:** Laravel 13, PHP 8.5, Livewire 4.4 SFC, Pest 5, Blade components (`x-card`, `x-table`, `x-modal`, `x-form.*`, `x-badge`), SQLite (dev and tests).

**Spec:** `docs/superpowers/specs/2026-11-20-products-settings-document-sequences-design.md` (sections A and Rollout)

## Global Constraints

- PHP 8.5, Laravel 12, Livewire 4.4 single-file components; files live under `resources/views/components/livewire/` with the `⚡` prefix.
- Routes use `Route::livewire()` inside the existing `['middleware' => ['auth']]` group in `routes/web.php`.
- Always pass `--no-interaction` to Artisan commands.
- Money columns are `decimal(15,2)`; stock quantities are `decimal(15,3)`.
- Stock = sum of `movement_type = in` minus sum of `movement_type = out`; a `null` sum means `0`.
- Lists paginate 10 rows, newest first (`latest('id')`), with `#[Url]` debounced search.
- Child components dispatch `product-created`, `product-updated`, `product-deleted`; the index listens with `#[On]` and shows an Alpine flash banner.
- Product types are exactly `product` and `service`.
- Do not stage or commit the user's unrelated uncommitted work; stage only the files listed in a task.
- After changing PHP, run `vendor/bin/pint <paths> --format agent`.
- Narrow test command: `vendor/bin/pest tests/Feature/ProductPagesTest.php --compact`.

## Review Focus

- A product with no stock movements must show stock `0`, not an empty cell or a PHP error (null sum). Tested in Task 3.
- A `service` product must show `—` for stock and must never receive a low-stock badge. Tested in Task 3.
- Updating a product must accept its own current code, SKU, and barcode without a unique violation. Tested in Task 5.
- Creating several products with empty SKU/barcode must store `null` and not collide on the unique indexes. Tested in Task 4.
- A search with no matches must render the empty-state row, not an empty table or an error. Tested in Task 3.

- [ ] **Step 3: Implement the index SFC**

Create `resources/views/components/livewire/catalog/products/⚡index.blade.php` following the shape of `resources/views/components/livewire/catalog/categories/⚡index.blade.php`.

PHP block requirements:

```php
use App\Enums\MovementType;
use App\Enums\ProductType;
use App\Models\Product;
use Livewire\Attributes\Computed;
use Livewire\Attributes\On;
use Livewire\Attributes\Url;
use Livewire\Component;
use Livewire\WithPagination;

new class extends Component {
    use WithPagination;

    #[Url]
    public string $search = '';

    #[Computed]
    public function products()
    {
        return Product::query()
            ->with(['category', 'brand', 'unit'])
            ->withSum(['stockMovements as stock_in' => fn ($query) => $query->where('movement_type', MovementType::IN)], 'quantity')
            ->withSum(['stockMovements as stock_out' => fn ($query) => $query->where('movement_type', MovementType::OUT)], 'quantity')
            ->when($this->search, function ($query) {
                $query->where(function ($query) {
                    $query->where('name', 'like', "%{$this->search}%")
                        ->orWhere('code', 'like', "%{$this->search}%")
                        ->orWhere('sku', 'like', "%{$this->search}%")
                        ->orWhere('barcode', 'like', "%{$this->search}%");
                });
            })
            ->latest('id')
            ->paginate(10);
    }

    #[On('product-created')]
    #[On('product-updated')]
    #[On('product-deleted')]
    public function refreshList(): void
    {
        //
    }
};
```

- Root Alpine flash block identical to the categories index, using `products.created`, `products.updated`, `products.deleted`.
- Page header with `products.title` / `products.subtitle` and an actions slot containing `{{-- create component wired in Task 4 --}}`.
- Search input bound with `wire:model.live.debounce.300ms="search"`.
- Table columns: `#`, code, name, category, brand, unit, type, selling price, stock, active, actions.
- Category/brand/unit render `$product->category?->name ?? '—'`, etc.
- Type renders `$product->type->label()`.

- Stock cell:

```blade

@endphp

@if ($product->type === \App\Enums\ProductType::Product)

@else
```
