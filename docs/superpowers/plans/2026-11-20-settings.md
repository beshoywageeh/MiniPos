# Settings Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a typed settings service and a fixed General settings page that edits the store identity, currency, tax rate, and invoice footer.

**Architecture:** A static `App\Support\Settings` class reads and writes the existing `settings` key/value table, casting by the stored `type`. One Livewire 4 single-file page under `livewire.settings` loads the six keys with defaults, validates them, and writes them back. No generic key/value editor, no cache.

**Tech Stack:** Laravel 13, PHP 8.5, Livewire 4.4 SFC, Pest 5, Blade components (`x-card`, `x-page-header`, `x-form.*`, `x-button`), SQLite (dev and tests).

**Spec:** `docs/superpowers/specs/2026-11-20-products-settings-document-sequences-design.md` (section B and Rollout)

## Global Constraints

- Routes use `Route::livewire()` inside the existing `['middleware' => ['auth']]` group in `routes/web.php`.
- Always pass `--no-interaction` to Artisan commands.
- `app/Support` is a new base folder, already approved in the spec.
- `Settings::get()` must return the caller's default when the key is missing; a missing row must never break the page.
- Types are exactly `string`, `integer`, `boolean`, `decimal`, `json`; unknown stored types read as strings.
- No caching.
- Keys and defaults: `company_name` (string, `MiniPOS Store`), `company_phone` (string, `''`), `company_address` (string, `''`), `currency` (string, `USD`), `tax_rate` (decimal, `0`), `invoice_footer` (string, `''`).
- Do not stage or commit the user's unrelated uncommitted work; stage only the files listed in a task.
- After changing PHP, run `vendor/bin/pint <paths> --format agent`.
- Narrow test command: `vendor/bin/pest tests/Feature/SettingsTest.php --compact`.

## Review Focus

- `tax_rate` is seeded with type `decimal`; `Settings::get('tax_rate')` must return the string `'10'`, and the page must render it without a type error.
- Saving blank phone, address, and footer must store `''` and not fail validation.
- `DatabaseSeedingTest` asserts the settings row count; it must move from `3` to `6` when the seeder is extended, or the full suite fails.
- `Settings::all('general')` must exclude other groups and cast each value by its own type.
- The page must load with no settings rows at all, using the defaults.

- [ ] **Step 3: Create the service**

Create `app/Support/Settings.php`:

```php
<?php

namespace App\Support;

use App\Models\Setting;

class Settings
{
    public static function get(string $key, mixed $default = null): mixed
    {
        $setting = Setting::query()->where('key', $key)->first();

        if ($setting === null) {
            return $default;
        }

        return self::castRead($setting->value, $setting->type);
    }

    public static function set(string $key, mixed $value, string $type = 'string', ?string $group = 'general'): void
    {
        Setting::query()->updateOrCreate(
            ['key' => $key],
            [
                'value' => self::castWrite($value, $type),
                'type' => $type,
                'group' => $group,
            ],
        );
    }

    /**
     * @return array<string, mixed>
     */
    public static function all(?string $group = null): array
    {
        return Setting::query()
            ->when($group !== null, fn ($query) => $query->where('group', $group))
            ->get()
            ->mapWithKeys(fn (Setting $setting): array => [
                $setting->key => self::castRead($setting->value, $setting->type),
            ])
            ->all();
    }

    private static function castRead(?string $value, string $type): mixed
    {
        return match ($type) {
            'integer' => (int) $value,
            'boolean' => filter_var($value, FILTER_VALIDATE_BOOL),
            'json' => json_decode((string) $value, true),
            'decimal' => (string) $value,
            default => (string) $value,
        };
    }

    private static function castWrite(mixed $value, string $type): ?string
    {
        return match ($type) {
            'boolean' => $value ? '1' : '0',
            'json' => json_encode($value),
            'integer' => (string) (int) $value,
            default => $value === null ? null : (string) $value,
        };
    }
}
```

PHP requirements:

```php
use App\Support\Settings;
use Livewire\Component;

new class extends Component {
    public string $companyName = '';

    public string $companyPhone = '';

    public string $companyAddress = '';

    public string $currency = '';

    public string $taxRate = '';

    public string $invoiceFooter = '';

    public bool $saved = false;

    public function mount(): void
    {
        $this->companyName = (string) Settings::get('company_name', 'MiniPOS Store');
        $this->companyPhone = (string) Settings::get('company_phone', '');
        $this->companyAddress = (string) Settings::get('company_address', '');
        $this->currency = (string) Settings::get('currency', 'USD');
        $this->taxRate = (string) Settings::get('tax_rate', '0');
        $this->invoiceFooter = (string) Settings::get('invoice_footer', '');
    }

    public function save(): void
    {
        $validated = $this->validate([
            'companyName' => ['required', 'string', 'max:255'],
            'companyPhone' => ['nullable', 'string', 'max:30'],
            'companyAddress' => ['nullable', 'string', 'max:500'],
            'currency' => ['required', 'string', 'max:3'],
            'taxRate' => ['required', 'numeric', 'min:0', 'max:100'],
            'invoiceFooter' => ['nullable', 'string', 'max:1000'],
        ]);

        Settings::set('company_name', $validated['companyName'], 'string');
        Settings::set('company_phone', $validated['companyPhone'] ?? '', 'string');
        Settings::set('company_address', $validated['companyAddress'] ?? '', 'string');
        Settings::set('currency', $validated['currency'], 'string');
        Settings::set('tax_rate', $validated['taxRate'], 'decimal');
        Settings::set('invoice_footer', $validated['invoiceFooter'] ?? '', 'string');

        $this->saved = true;
    }
};
```
